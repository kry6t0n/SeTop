# Функциональные требования MVP для Network Topology Visualizer

## Use Case: Создание и валидация сетевой топологии

**Актор:** Сетевой инженер

**Основной сценарий:**

1. **Аутентификация и доступ:**
   - Пользователь открывает приложение
   - Система перенаправляет на страницу входа
   - Пользователь вводит credentials (engineer/engineer123)
   - Система проверяет учетные данные и предоставляет доступ к редактору

2. **Создание нового проекта:**
   - Пользователь нажимает "New Project" в Dashboard
   - Система открывает редактор с пустым холстом
   - Пользователь видит панель инструментов с типами устройств

3. **Добавление сетевых устройств:**
   - Пользователь выбирает тип устройства (Router, Switch, Server, Workstation, Network)
   - Перетаскивает устройство на холст
   - Система создает соответствующий узел с уникальным ID
   - Узел отображается со стилизованной иконкой и placeholder данными

4. **Конфигурация свойств устройства:**
   - Пользователь кликает на устройство
   - Система отображает панель свойств в сайдбаре
   - Пользователь заполняет свойства:
     - Hostname/Device Name
     - IP Address (с валидацией формата)
     - Subnet Mask (CIDR notation)
     - Дополнительные device-specific параметры
   - Система валидирует введенные данные в реальном времени

5. **Создание соединений между устройствами:**
   - Пользователь кликает на порт исходного устройства
   - Перетаскивает connection handle к целевому устройству
   - Система автоматически определяет возможные типы соединений:
     - Physical (синяя сплошная линия)
     - Routing (фиолетовая пунктирная линия)
     - Logical (зеленая двойная пунктирная линия)
   - Система валидирует совместимость устройств и IP подсетей

6. **Настройка параметров соединения:**
   - Пользователь выбирает созданное соединение
   - Система отображает свойства соединения в сайдбаре
   - Пользователь настраивает:
     - Connection Type (Physical/Routing/Logical)
     - Status (Active/Inactive/Error)
     - Bandwidth
     - Description
   - Визуальное отображение соединения обновляется согласно настройкам

7. **Валидация сетевой топологии:**
   - Пользователь нажимает "Validate Network"
   - Система выполняет комплексную проверку:
     - Проверка уникальности IP адресов
     - Валидация подсетей и совместимости соединений
     - Проверка connectivity между устройствами
     - Выявление циклических зависимостей
   - Система отображает результаты валидации с детализацией ошибок

8. **Сохранение проекта:**
   - Пользователь нажимает "Save Project"
   - Система сериализует топологию в JSON формат
   - Данные сохраняются в browser localStorage
   - Пользователю показывается подтверждение успешного сохранения

9. **Экспорт конфигурации:**
   - Пользователь нажимает "Export Project"
   - Система генерирует JSON файл с полной конфигурацией
   - Браузер автоматически скачивает файл
   - Файл содержит все данные о устройствах, соединениях и настройках

**Альтернативные сценарии:**

- **Ошибка валидации IP:** Система показывает сообщение об ошибке и подсвечивает невалидное поле
- **Несовместимые устройства:** Система блокирует создание соединения и показывает подсказку о причинах
- **Дублирование IP:** Система обнаруживает конфликт и предлагает автоматическое разрешение
- **Потеря соединения:** При попытке сохранить в оффлайн-режиме система уведомляет пользователя

**Постусловия:**
- Сетевая топология полностью сконфигурирована и валидирована
- Все устройства имеют корректные IP адреса и настройки
- Соединения соответствуют сетевым стандартам и best practices
- Проект сохранен локально и доступен для последующего редактирования
- Конфигурация экспортирована в переносимом JSON формате

## Критерии приемки MVP

- [x] Пользователь может аутентифицироваться с ролью Network Engineer
- [x] Пользователь может создавать проекты сетевых топологий
- [x] Поддерживается 5 типов сетевых устройств с визуальным представлением
- [x] Реализовано 3 типа соединений с различным визуальным оформлением
- [x] Работает валидация IP адресов и подсетей в реальном времени
- [x] Система проверяет совместимость устройств при создании соединений
- [x] Пользователь может сохранять проекты в localStorage
- [x] Пользователь может экспортировать проекты в JSON формате
- [x] Интерфейс отзывчив и поддерживает топологии до 50 устройств
- [x] Реализована панель свойств для редактирования параметров устройств и соединений
